# Leonhfr Tap

## How do I install these formulae?

`brew install leonhfr/tap/<formula>`

Or `brew tap leonhfr/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "leonhfr/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
